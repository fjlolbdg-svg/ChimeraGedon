# キメラゲドン（ChimeraGedon）とは

スマホ（Android / iOS）向けの、オンライン対戦の**正体隠匿チームバトル**。4〜8人（おすすめ6人）、1試合6〜10分。

## ひとことで

**「ガチャから出た色で、味方が変わる。」**

試合が始まると、ガチャマシンから1人3つのカプセルが出てくる。中身は自分が選んだ**頭・胴・脚**の部位で、それを装着して1体の「キメラ」になる。
**カプセルの色（赤・青・緑）が陣営の色**。誰が何色かは最初は分からない。

## 陣営の決まり方

- 同じ色が2つ以上 → その色の陣営（例: 赤赤青 → 赤）
- 3色バラバラ → **緑**陣営

## 勝ち方

- **赤**: 生き残っている青を全員倒す
- **青**: 生き残っている赤を全員倒す
- **緑**: 緑カプセルに入っている秘密の「使命」（例: HP5以上で生き残る、装備を2つ集める）を達成する。赤青と一緒に勝てる

## 1ラウンドの流れ（全員同時に決める）

1. **移動**: 留まるか、隣のエリアへ1つ動く（マップは4エリア: 祭壇・研究所・闘技場・巣）
2. **行動**: 次の4つから1つ ＋ 手札を1枚まで
   - **攻撃**: 同じエリアの1人に、エネルギー（EN）を秘密で賭ける
   - **チャージ**: EN+3
   - **ドロー**: 3つの山札（解析・治療・呪術）から引く
   - **公開**: 自分の部位を1つ見せて、そのスキルを使う（色がバレる）
3. **ガード**: 狙われた人は、防御に使うENを秘密で決める。攻撃のENの方が大きければ命中
4. 7ラウンド目から「終末」で全員が毎ラウンド削られ、10ラウンド目が終わったら最終審判

## このゲームの肝

- 部位を**公開**すると強いスキルが使えるが、色がバレる（最大3回）
- **未公開の部位は交換できる**。交換で色が入れ替わると、**陣営そのものが変わる**。さっきまでの味方が敵になる
- 部位には隠したまま効く「潜伏スキル」もある（例: キツネの頭は、推理カードにウソの答えを返せる）
