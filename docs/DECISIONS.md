## D-01 緑陣営の判定

**決定（2026-10-21, FJ）: A 同じ色2つ以上ならその色、3色バラバラなら緑。**

原案: 「赤・青・緑なら緑」「緑・赤なら緑」。

- **A（推奨）多数決＋バラバラは緑**: 同じ色が2つ以上ならその色。3色バラバラなら緑。
  緑は「緑2つ」か「3色バラバラ」でしかなれないので、人数をコントロールしやすい。
- B 感染ルール: 緑が1つでも入ったら緑。
  「緑の部位を押し付けると相手が緑になる」という感染ゲームになって面白いが、緑が増えすぎやすく、横取り勝利（D-02 A）と組み合わせると荒れる。

## D-02 緑陣営の勝ち方

**決定（2026-10-21, FJ）: C 緑は特殊勝利条件（使命）を持つ。** 例として FJ が挙げたのは「赤か青が勝ったとき体力7なら勝ち」「装備を3つ以上集める」。

- A 横取り: 赤か青が勝つ瞬間に緑が生きていれば緑だけの勝ち。（不採用）
- B 相乗り: 生きていれば一緒に勝ち。（不採用）
- **C 使命**: 緑ごとに秘密の勝利条件を持ち、達成すれば赤青と一緒に勝つ。一覧は PARTS_AND_CARDS.md 3章。
  - 残っている選択肢: 難しい使命だけ「横取り（赤青を負けにする）」にするか。勝率を見てから決める。

## D-03 部位と色の関係

**決定（2026-10-21, FJ）: A 別々。色は試合ごとにランダム。** イメージは「ガチャマシンから3つのカプセルが出てきて、中の部位を装着する。カプセルの色が陣営色。中身はホストのガチャマシンが決める」。

## D-04 手番の進め方

- **A（推奨）全員同時に決めて一斉解決**: 8人でも1ラウンド1分弱。スマホで「他人の番を待つ」時間がほぼない。ボードゲームでは管理が大変だがアプリなら自動でできる。
- B 1人ずつ順番（DOUBT! と同じ）: 実装はやや簡単。8人だと待ち時間が長く、スマホではだれやすい。

## D-05 攻防の決め方（サイコロ問題）

原案: エネルギーで攻撃・防御。集団リンチ対策でサイコロも検討。ただし『シャドウハンターズ』に似すぎる心配。

- **A（推奨）エネルギーの秘密入札**: 攻撃側と防御側が同時に秘密でENを賭け、攻撃が上回れば命中。運ではなく読み合い。秘密の同時入力はアプリだからこそ自然にできる。
- B ルーレット: 攻撃時に画面のルーレットで倍率を決める。運要素は入るが、サイコロと本質は同じ。
- 参考: リンチ対策は入札ではなく、エリア制限・ガード一括・被ダメ上限で行う（GAME_SPEC 4-4）。

## D-06 マップ

- **A（推奨）2×2 の4エリア、毎ラウンド隣へ1歩移動、攻撃は同エリアのみ**: エリアごとに効果（祭壇・研究所・闘技場・巣）。
- B 初期配置をルーレットで決める: 運の面白さはあるが、最初の配置で不利が決まりやすい。A の時間切れ時だけランダムにしている。
- C マップなし（席の両隣だけ攻撃できる）: シンプルだが、リンチ対策が弱く、読み合いの材料も減る。
- 注意: 「エリアと山札が1対1で結びつく」形は『シャドウハンターズ』に近いので避けた（研究所はドローが安いだけで、どの山札も引ける）。

## D-07 人数とボット

- **A（推奨）4〜8人、推奨6人。足りない席・切断した席はボットが入る**。
- B 実プレイヤーだけ（DOUBT! と同じ）: 正体隠匿は人数が欠けると成り立ちにくい。

## D-08 チャット

- **A（推奨）スタンプ＋定型文のみ**（名前差し込み可）。自由入力なし。
- B 自由チャットあり: 盛り上がるが、ランダムマッチでの荒らし・ストア審査（年齢区分）の負担が増える。

## D-09 秘密情報をどこに置くか

- **A（MVP で仮採用）ホスト端末**: DOUBT! と同じ方式ですぐ作れる。改造クライアントのホストなら色が見える。
- B 専用サーバー / Cloud Code: ランダムマッチを本格運用するなら必要。費用と実装量が増える。

## D-10 3つの山札の構成

原案: 推理・回復・効果ダメージの3つ、エネルギー2で好きな山を引く。

- **A（推奨）原案どおり3つ。ただし推理は「結果が本人だけに見える」方式、呪術に部位交換カードを入れる**: 『シャドウハンターズ』の「カードを相手に渡して正直に答えさせる」方式とは別物にした。上から2枚見て1枚選べるので、運に振り回されにくい。
- B 山札を1つにまとめる: 選ぶ楽しさは減るがUIが簡単になる。

## D-11 部位ごとの HP の扱い

FJ: 「頭と胴体と足それぞれに体力とスキルがある」。

**決定（2026-10-21, FJ）: A 合計HP方式。**

- **A（推奨・仮採用）合計HP方式**: キャラクターの最大HP = 3部位の HP の合計。ダメージはキャラクター全体で受ける。交換で最大HPが変わる。強スキルの部位ほど HP を低くして釣り合いを取り、コスト制限は廃止。
- B 部位ごとに削る方式: 攻撃で部位を狙い、HP0 になった部位は壊れてスキルが使えなくなる。読み合いは深くなるが、操作と画面が複雑になりスマホ向きではない。

## D-12 緑の使命の持ち方

- **A（推奨・仮採用）緑カプセルに封入**: 使命は緑カプセルごとに1つ入っていて、交換でカプセルと一緒に移動する。緑カプセル2つなら使命も2つ。「交換で使命ごと奪われる」ドラマが生まれる。
- B 緑陣営になった人に1つ配る: 分かりやすいが、途中で緑になった人の扱いが別途必要。
