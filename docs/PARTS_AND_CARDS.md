# キメラゲドン 部位・カード・緑の使命 一覧

> [!AI-AGENT-INSTRUCTION]
> ルールの前提は `docs/GAME_SPEC.md`。ここはデータ表です。
> 実装では ScriptableObject（`PartData` / `CardData` / `MissionData`）に1行＝1アセットで落とし、ID はこの表の ID をそのまま使う。
> 用語: 「同エリア」=自分と同じエリア、「隣接」=同エリア＋隣のエリア、「ガード不能」=4-3の入札を通さず直接ダメージ。
> スキル・カードのダメージも 1ラウンドの被ダメージ上限（5）に含む（毒は別枠）。
> 「公開」=公開スキル（公開時に1回。【常時】は公開後ずっと）、「潜伏」=潜伏スキル（未公開のあいだだけ有効、公開で消える）。

## 1. 部位（初期18種）

スロットごとの役割:
- **頭** = 情報と操作（見る・入れ替える・封じる・ウソをつく）
- **胴** = 守りと持久（回復・軽減・反撃）
- **脚** = 移動と攻め（踏み込む・逃げる・罠）

HP の目安: 頭2〜4、胴3〜6、脚2〜4。**スキルが強い部位ほど HP を低くする**（コスト制限の代わり）。

### 調整メモ

- 交換系（H02 / H05 / カード「移植手術」）がゲームの肝。多すぎると推理が成り立たないので、**1試合あたり交換が平均2〜4回**を目標に調整する。
- ウソ系（H03 / T06）は推理を崩す。強すぎたら回数を減らす。解析の結果画面には「ウソの可能性あり」とは**表示しない**（疑うのはプレイヤーの仕事）。
- 数値は全部初期値。AI 同士の自動対戦で勝率を取ってから調整する（TECH_SPEC のシミュレーター）。

## 2. カード（3つの山札）

各山札は 16 枚で開始。使い切ったら捨て札を混ぜ直す（シード付き乱数）。
【装備】カードは使うと自分の前に置かれ、ダウンするか効果で外れるまで有効（1人3個まで、全員に見える）。

## 3. 緑の使命（特殊勝利条件）

緑のカプセルに1つずつ封入される（GAME_SPEC 2-5）。同じ試合で同じ使命は出ない。持ち主が緑陣営のときだけ有効。**どれも赤青の勝敗とは別に判定し、達成すれば緑も勝ち**（赤青と一緒に勝てる）。

| ID | 名前 | 条件 |
|---|---|---|
| M01 | 不死身 | 試合終了時に生存していて、HP が 5 以上 |
| M02 | 収集家 | 試合終了時に装備を 2 個以上付けている（ダウンしていても可。ダウン時の装備数で判定） |
| M03 | 寄生 | 試合中に自分が関わる交換が 2 回以上起き、試合終了時に生存している |
| M04 | 隠者 | 試合終了時に生存していて、公開された部位が1つ以下 |
| M05 | 完全体 | 試合終了時に生存していて、3部位すべてが公開されている |
| M06 | 天秤 | 試合終了時、ダウンした赤陣営と青陣営の人数が同じ（1人以上） |
| M07 | 漁夫の利 | 自分の攻撃・スキル・カードで2人以上をダウンさせ、試合終了時に生存している |
| M08 | 道連れ | 自分がダウンしたラウンドに、自分を攻撃した人のうち1人以上もダウンする |

### 調整メモ

- 使命の難しさにばらつきがあるので、勝率を見て「難しい使命ほど横取り勝利（赤青を負けにする）」にする案も残す（`DECISIONS.md` D-02）。
- 緑カプセルを2つ持つ緑は使命も2つになり有利。勝率が高すぎたら「2つのうち1つを試合開始時に選ぶ」にする。
